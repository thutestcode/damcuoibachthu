# Lora

Regular (400) and semibold (600), self-hosted TrueType fonts. The full character sets include Vietnamese accents. Distributed under SIL Open Font License 1.1; see `OFL.txt`.

Official family: https://fonts.google.com/specimen/Lora

Source files:
- https://fonts.gstatic.com/s/lora/v37/0QI6MX1D_JOuGQbT0gvTJPa787weuyJG.ttf
- https://fonts.gstatic.com/s/lora/v37/0QI6MX1D_JOuGQbT0gvTJPa787zAvCJG.ttf

License source: https://github.com/google/fonts/blob/main/ofl/lora/OFL.txt

The site serves these files from `assets/fonts/`; visitors do not need to contact Google Fonts. Georgia is the serif fallback during loading.
