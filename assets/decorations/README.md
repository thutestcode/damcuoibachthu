# Burgundy floral ornament

Asset: `burgundy-flowers.png`, transparent PNG, created for the Anh Thư & Thanh Bách wedding invitation using the built-in image generation tool.

Design prompt:

> Use case: illustration-story. Asset type: transparent watercolor floral botanical ornament for an elegant burgundy wedding invitation website. Generate one isolated airy asymmetrical curved botanical spray, square composition, flowers flowing diagonally from lower-left to upper-right with open space around the silhouette. Delicate hand-painted watercolor, translucent petal edges, understated fine-art wedding stationery style. A few small deep wine/burgundy cosmos flowers and pale blush sweet pea blossoms, one soft ivory garden rose, fine branching stems and sparse dusty taupe/eucalyptus leaves. Predominantly ivory and dusty blush with restrained burgundy accents; the ornament must look light, graceful, calming and readable behind dark burgundy text. Not a dense bouquet. True transparent background, no white rectangular canvas, no border, no frame, no typography, no text, no watermark. Designed to reuse as corner decorations and large very faint background washes. Keep the entire spray within frame with generous transparent margins. Save a high quality PNG asset.
